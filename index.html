Panduan Demo Setup Sheet (Cukup 1 Kali Klik):
  1. Buka Google Sheet Anda via tombol "Buka Google Sheet" di atas.
  2. Di Google Sheet, klik menu Ekstensi > Apps Script.
  3. Klik tombol "Salin Script Google Sheet" di atas, lalu Paste ke editor Apps Script.
  4. Pilih fungsi initDatabase di dropdown atas, lalu klik Jalankan (Run).
  5. • Seketika Sheet Master_Kerusakan, Bookings, & Master_Sites langsung otomatis terbentuk lengkap dengan data & warnanya!

Didapatkan dari Apps Script: Terapkan (Deploy) > Deployment baru > Aplikasi web (Akses: Siapa saja). Jika URL ini diisi, setiap booking baru dan perubahan status servis akan otomatis tersimpan langsung ke baris Google Sheet!

PENTING: Mengatasi Error 403 (Forbidden) saat Simpan Data:

Jika muncul error 403 (Forbidden) di console/browser, artinya izin akses di Google Apps Script masih "Hanya saya".

  1. Di Google Apps Script, klik tombol Terapkan (Deploy) > Kelola Deployment.
  2. Klik ikon Pensil (Edit).
  3. Pada opsi "Siapa yang memiliki akses" (Who has access): ubah menjadi "Siapa saja" (Anyone).
  4. Klik Terapkan • Selesai! Web app kini dapat langsung menyimpan data ke Google Sheet.
